# jei_compat — optional Just Enough Items plugin for Elsewhere (v0.1.0)

JEI for Fabric 26.3 = `jei-26.3-fabric-31.17.0.109` (Modrinth / maven.blamejared.com). It must be on the **server and the client** (since 1.21.2 vanilla servers don't send recipes). Elsewhere's standard recipes (crafting, stonecutting, smithing, 26.3's data-driven `minecraft:brewing`) need no plugin; this plugin adds what JEI can't see on its own.

## What it adds
- **Wayfinder Attunement** category (`elsewhere:wayfinder_attunement`): one page per `data/elsewhere/attunement/*.json` (7 dimensions): base Wayfinder in the middle of a 3×3 grid with the dimension's 5 ingredients in the DIMENSIONS.md §8 layout (a b a / c W c / d e d) → `elsewhere:wayfinder_<dimension>`; a line "Any layout works"; The Hush page says in red that the Ender Dragon must have been killed. Catalysts: crafting table, crafter. JEI's "+" transfer fills a crafting table (input slots are in grid order). The attunement files are read from the Elsewhere jar itself (works on dedicated servers, where the client never sees data packs). The only custom recipe serializer in the 0.3.0 jar is `elsewhere:attunement` (checked); everything else is a vanilla type.
- **Info pages** (`addIngredientInfo`) for 206 registered items, from `assets/elsewhere/jei/info.json` (generated by `tools/gen_info.py` from `Ideas/catalog.json`, kept only for item names that exist in the jar's en_us.json): what the item does, how to get it (trader, boss, craft, loot), for boss drops which boss drops it, where, and how to summon it; for summon items (Heartwood Effigy, Moonring Seed, Siren Conch, Frozen Heart, Lighthouse Lantern, Snack Altar) which boss they summon and where; the Herding Crook's orders (minions only attack players/pets/villagers/golems you mark); the Calling sentence on caster/summoner armor; trader sources (Windwright, Dune Factor, Tidewright, Quartermaster, Budtender, Mute Archivist, Sap Tapper). Items the catalog doesn't describe fall back to their own tooltip lines. Lines are `translatableWithFallback("jei.elsewhere.info.<item>.<n>", text)`, so no lang merge is needed (translations can add the keys later).
- **Hidden** from JEI's item list: `elsewhere:arena_seal`, `elsewhere:return_rift` (technical blocks).
- Category title key `jei.elsewhere.wayfinder_attunement` (fallback "Wayfinder Attunement").

## Merge (integration)
1. Copy `src/main/java/dev/elsewhere/compat/jei/*.java` (4 files) into Elsewhere's **client** source set (`src/client/java/dev/elsewhere/compat/jei/`), and `src/main/resources/assets/elsewhere/jei/info.json` into Elsewhere's resources.
2. Elsewhere `fabric.mod.json`: add `"jei_mod_plugin": ["dev.elsewhere.compat.jei.ElsewhereJeiPlugin"]` to `entrypoints`, and `"suggests": {"jei": "*"}`.
3. Elsewhere `build.gradle`: repository `exclusiveContent { forRepository { maven { url = "https://maven.blamejared.com/" } }; filter { includeGroup "mezz.jei" } }` and
   `compileOnly "mezz.jei:jei-26.3-common-api:31.17.0.109"`, `compileOnly "mezz.jei:jei-26.3-fabric-api:31.17.0.109"` (if the plugin is in the client source set, Loom's split source sets see `compileOnly`; else use `clientCompileOnly`). Never `include`/bundle JEI. For a dev run with JEI: `runtimeOnly("mezz.jei:jei-26.3-fabric:31.17.0.109") { transitive = false }` (its pom names mezz_config, which is not on that maven but is nested in the JEI jar).
4. Nothing else references the package; without JEI the entrypoint is never loaded, so Elsewhere runs unchanged.
5. The plugin uses only registry lookups by id (no Elsewhere classes), so it compiles in place.

## Tested
- Client gametest on the iMac (JEI 31.17.0.109 both sides, singleplayer, RC jar + this module): `@elsewhere` lists 400 entries, arena_seal hidden, 7 attunement pages, 185 info pages (186-page version), JEI brewing shows the Glimmer Tonic recipes (Clarity Draught outputs are vanilla potions with Elsewhere potion contents), ALL PASSED. Screenshots in `screenshots/` (iMac screenshots drop the lowercase 'f' glyph; not a mod issue). The attunement note text in those shots is the old longer version (fixed 20:51).
- Production server with JEI + this module + TM + GL 2.0.1: clean.

## Not done / gaps
- Info texts come from the design catalog; where the built item differs from the design, the page may be slightly off (regenerate with `tools/gen_info.py` once docs match). Items the catalog lists as sets ("Sunstone tools") don't get pages; 59 catalog names don't match a registered item.
- No custom category for boss loot or trader trades (they are info pages).
