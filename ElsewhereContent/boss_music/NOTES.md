# boss_music (client-only module)

One music theme per boss, plus summon / phase / victory stingers.

- Map: `src/main/resources/assets/elsewhere/boss_music.json` (boss entity id -> sound event; also range, fades, phase thresholds). Add a boss here, no code change.
- Events: `assets/elsewhere/sounds.json` (`boss_music.theme.<slug>` streamed, `boss_music.sting.{summon,phase,victory}`), OGGs in `assets/elsewhere/sounds/music/`: per theme `<track>_intro.ogg` (played once) and `<track>_loop.ogg` (the body, looping, no intro/outro), events `boss_music.theme.<slug>.intro` / `.loop`, generated by `_tools/make_loops.py --install` from `ElsewhereContent/audio/music` and kingdom_court's tracks (points in `audio/LOOPS.md`). `boss_music.json` has `intro_ticks` per theme (loop starts 1 tick before the intro ends, with a 0.4 s ramp over the intro's fading tail).
- Service: `BossMusicService` (tick), `Theme` (intro then loop), `FadingMusic` (MUSIC category, fades), `MusicManagerMixin` pauses vanilla music while a theme plays.
- Toggle: `/elsewhere_bossmusic true|false`, stored as `bossMusic` in `config/elsewhere-client.json`; also ANDs `ElsewhereHud.flag("bossMusic")` if that class exists.
- Check: `tools/check_map.py` (static, against the merged tree), `tools/check_loops.py` (no click at any loop wrap / intro hand-off), `./gradlew runClient` self-test (resources resolve).
- Older per-module boss music (`overworld_bosses` / `nether_end_bosses` BossMusic mixins) keeps working but is paused whenever this module plays a theme.

## 3.0 (music lane)
- **Conductor** (`Conductor.java`, pure logic): intro = the track's own opening (`native` full level, `cold` 2-tick ramp; no generic fade), loop hand-off as before; each phase threshold with a **phase layer** (P12 stems, `themes.<id>.layers`) = equal-power crossfade, one beat long, on the next real beat into that layer; a threshold without one = the phase stinger on the beat (at most 2 streams ever: a swap waits for a running crossfade or the intro hand-off; both thresholds at once = only the deeper layer); **victory** = on the next beat the body fades over one beat while the track's own final cadence (`.end`, all 45 themes) plays to its natural end; **flee** (range/reset/despawn/other boss) = 50-tick fade from the next beat; **defeat** = 80-tick fade. No part plays twice; a second boss's theme waits for the first to leave. The summon stinger is off (`summon_stinger`), each theme's own opening is the cue.
- **Phase layers (P12)**: `"layers": [{"phase": 0, "name": "surge", "loop_ticks": .., "phase_ticks": ..}, {"phase": 1, "name": "climax", ..}]`, event `boss_music.theme.<slug>.<name>`, file `boss_<slug>_<name>.ogg`. 25 themes: 16 surges (threshold 0, the loudest ~24 s) + 11 climax stems (threshold 1, the hottest ~8-18 s bars, >= 0.5 dB above the section before). Cut by `_tools/make_loops.py --sections --no-gen --climax --install-layers` (`--install` keeps them too). No `layers` key = the 2.x/early-3.0 surge fields. A missing event = stinger, never a silent part.
- **No reflection, no scans**: boss bars via mixin `BossOverlayAccessor`; boss candidates from `ClientEntityEvents` load/unload, looked at every 5 ticks only while a themed boss is loaded.
- **Data**: `boss_music.json` `themes` (per theme: intro, intro/beat/loop/surge/end ticks, beat phases, layers), `shared_themes` (hrolf+grimhorn, grunthar+ashtusk: one fight each), boss map from `audio/fit/scores.json`. Made by `_tools/make_loops.py --sections --phases --no-gen --install`.
- **RealmGuard** + `SoundManagerMixin`: while a theme plays, kingdom realm tracks (`*.realm`) are not started and the court's stop-all-music (sent before each 240 s realm resend) is ignored; a realm track already playing fades over 30 ticks when a theme starts.
- **Kill switch**: `"bossMusic3": false` in `config/elsewhere-client.json` (or `-Dboss_music.overhaul3=false`) = the 2.x behaviour (generic fades and stingers, no beat sync, surge, endings or realm guard).
- **Checks**: `tools/check_music.py` (slots resolve, documented shares, seam gate + wrap clicks for loops and layers, plan vs file lengths, layers valid and rising, court titles by id, 135 MB budget, credits); `ConductorSim` runs every theme through 10 scenarios inside the client self-test (`[boss_music-selftest]` PASS/FAIL + TOTAL).
- **In-game test**: `InGameTest` (`-Dboss_music.selftest=true` on first join, or `/elsewhere_bossmusic selftest`): court packets through the client listener, stand-in boss, realm fade/hold/resume, every layer, <= 2 streams; `[boss_music-ingame-selftest] TOTAL`, then system property `boss_music.ingame.done=true`.
- **Court titles**: matched by id (`audio/fit/court_titles.json`: title + catalog length per court id), not by list order.
- **Fit**: `_tools/music_fit.py [--html]` (profiles `audio/fit/profiles.json`, tags `audio/fit/tracks.json`) writes `audio/fit/scores.json` and `Review/music-fit.html`.

## 3.0 fit pass (s-music-fit)
- Install the fit scorer's choice with `_tools/music_fit.py` then `_tools/music_fit_install.py` (targeted; keeps `layers`). Late-section loops get a lead-in intro from `_tools/music_leadin.py` (`loops.json` `leadin`, exact `intro_len`).
- `court_music.realm` (Aldermark realm ambient) is defined here: `realm_aldermark` (Village Consort) + `realm_aldermark_lute` (Suonatore di Liuto), built by `audio/make_realm_2.1.py ... aldermark,aldermark_lute`.
- No orphan themes: every `boss_music.theme.*` event belongs to a theme a boss plays (`check_music.py` CHECK fit, `FitCheck` in the client self-test).
