# Kingdom of Aldermark: character gallery

Elsewhere 2.0.0 (Fabric 26.3). In-game shots are the ground truth (superflat world, noon, AI frozen, HUD hidden). Skin sheets are 10x paper dolls rendered from the 64x64 skins with the overlay layer, plus a second sheet with the vanilla humanoid armor layers on top, tinted and trimmed per the unit loadout JSON (units with several trim patterns pick one by UUID, so one doll per pattern is shown).

Regenerate the sheets with `tools/make_skin_sheets.py` and this page with `tools/make_readme.py`.
